local/z5b at 668a1d3 (the character code's decoder rewrite): what `DictIndex::id` and `key_into`
cost at the default block in three builds of the library over the same keys, in one process --

  4.2.0     from crates.io; every blob `BDX3`
  4.3.0     the tag v4.3.0; `BDX4` where the character code pays, and its first decoder
  668a1d3   the tree under test, which has to write 4.3.0's blob byte for byte -- the harness
            rebuilds it at the start of the run and asserts that on every corpus

Four of the files `bench/corpora.json` names: jieba's lexicon (349 045 keys) and a million titles
each in Chinese, Russian and English. Per corpus, 200 000 probes, every one a hit, shuffled with a
fixed seed and laid end to end in one arena so that the probes' own bytes stream. Before any timing,
every probe's id is checked equal across the three builds and every `key_into` checked to give the
probe back. Each build's index is loaded from its blob twice, at different times, so that one
placement in physical memory is not mistaken for the code; within a load, seven rounds of the
builds in the order A-B-C-C-B-A for `id` and again for `key_into`, with a `HashMap<&str, u64>`
lookup of the same probes -- which no build can move -- before and after each round as the control.
28 passes a build; each line of a run gives the median and, in brackets, the minimum. `id` takes a
`&str`, `key_into` writes into one reused `String`.

The whole run was taken twice, by two builds of the harness whose code layout differs, since on a
miss-bound probe loop alignment alone moves a few per cent. Both are below.

AMD Ryzen 7 5800HS (8 cores, 16 MB L3), 38 GiB DDR4-3200 in unequal channels (layout not read here
-- needs root; the physical placement of each load not recorded), Fedora 44, Linux
7.2.7-200.fc44.x86_64, rustc 1.98.1, governor powersave. The run started only once a readiness
check passed -- one-minute load 0.29, no swap in use, no other process over 15 % CPU, 6.1 h up --
and the hottest thermal zone read under 70 C: 47 C at the start, 82 C between the two builds, 87 C
at the end. The controls of the two builds agree within 1.7 % on three corpora of four and within
