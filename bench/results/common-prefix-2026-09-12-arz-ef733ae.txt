# Supersedes common-prefix-2026-09-12-arz-4fc92ac.txt: a block is now cut into microblocks, the
# default block is 256, and the second `DictIndex` row moves from 128 to 512.
#
# Protocol: one process, structures built once, 20 000 queries shuffled with a fixed seed, the
# variants alternated within each of five rounds, minimum per cell. Every structure is first held
# to marisa's answer on 2 000 of the queries, so the timings compare the same work. Queries are a
# real word plus one to three more letters, except every fourth, which is random letters; nearly
# all still match, because single letters are words. Nanoseconds per query, through Python -- the
# call overhead is in every row, and marisa-trie, dawg2 and datrie are C extensions too. Three
# runs; the page quotes the minimum of the three.
#
